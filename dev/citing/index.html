    Citing & Support¶

    Contact¶

    For bug reports, feature requests, and questions, use GitHub Issues.

    For broader discussion — use cases, ideas, or community questions — use GitHub Discussions.

    Citing¶

    If you use light-curve in your research, please cite Malanchev et al. 2021. When you use specific components described in their own papers — feature extractors, dm–dt maps, the rainbow multiband model, or the ML embeddings — please also cite the relevant papers linked throughout the documentation.
